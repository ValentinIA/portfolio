## Objetivo

Desarrollar modelos de clasificación supervisada capaces de identificar el riesgo de impago
de un solicitante de crédito.

## Trabajo realizado

- Preparación de los datos y análisis exploratorio (EDA).
- Selección de variables.
- Evaluación de algoritmos de clasificación.
- Implementación de un pipeline serializado con Joblib.

## Próximos pasos

Convertir el proyecto en una demostración interactiva: exponer el modelo mediante una
API REST independiente con FastAPI y consumirla desde este portfolio, para introducir
los datos de un solicitante y obtener la predicción.
